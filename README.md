Westside Roleplay is a German-language roleplay gamemode for Multi Theft Auto: San Andreas (MTA:SA).

The gamemode includes various roleplay systems such as jobs, factions, houses, vehicles, quests, achievements, criminal activities and several additional gameplay features.

## 👤 Accounts & Player Progression

Westside Roleplay includes its own registration and login system with MySQL persistence.

The gamemode provides several systems for managing player accounts and progression, including:

- Registration and login
- Persistent player data
- Player levels and experience
- Quest system
- Achievements
- Player statistics
- Spawn point selection
- Payday system
- Inventory and items
- Account-related administrative functions

The integrated level and quest systems provide additional progression opportunities beyond regular roleplay activities.

## 👮 Factions & Organizations

Westside Roleplay includes an extensive faction system with various government organizations, criminal factions and other groups.

The gamemode contains implementations for several factions, including:

- Yakuza

Factions have access to different features depending on their organization, including faction vehicles, headquarters, gates, teleporters and faction-specific interactions.

## ⚙️ Installation

1. Place the `WestsideRoleplay` folder inside your MTA server's `resources` directory.
2. Install the required MTA MySQL module for your server architecture (32-bit or 64-bit). Compatible module files are included in the repository.
3. Create a MySQL database and import the included `westsideroleplay.sql` file.
4. Configure the database connection in the gamemode's MySQL configuration files (Mysql/Mysql_start.lua).
5. Ensure the required MySQL module is loaded by your MTA server.
6. Start the `WestsideRoleplay` resource.

MySQL Module:  
https://wiki.multitheftauto.com/wiki/Modules/MTA-MySQL

## ⚠️ Important Notes

This gamemode is outdated and does not use Multi Theft Auto’s internal database functions. The MySQL module is required. Additionally, some systems may no longer work due to outdated functions. The gamemode includes everything a roleplay script needs: jobs, factions, houses, quests, various side and faction activities, and more. Some images, like the speedometer, are damaged and no longer load.
